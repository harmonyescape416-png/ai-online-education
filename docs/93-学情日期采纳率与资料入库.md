## 接口

见 `docs/api-extension.md`。首次提交和失败重试是两条接口。

日期：`YYYY-MM-DD`，上海时区，`[开始日 00:00, 结束日次日 00:00)`。两端必须同时有或同时没有。

采纳率：`aiAdoptedCount / aiSampleCount * 100`，保留 1 位小数。样本为 0 时 `aiAdoptRate=null`，`aiSampleCount=0`。

知识库阶段：`NOT_SUBMITTED`、`REVIEW_PENDING`、`INDEXING`、`SEARCHABLE`、`FAILED`、`WITHDRAWN`。审核通过不等于已经可检索。

失败后的「重试索引」调用 `POST /teacher/resources/{id}/retry-kb`，课程服务再调用 `POST /internal/ai/knowledge/retry-resource`。服务端按资源 ID 找原文档，不接受调用方传入文档 ID。只有已审核、索引失败且来源仍有效的文档会重新入队。待审核、已撤回、已删除、已替换不能借重试发布。重复点击返回同一进行中任务。成功入队后阶段是 `INDEXING`，不是 `SEARCHABLE`。
