# 学习笔记

笔记放在学习服务，和课程问答分开。默认私有。

## 谁能看

- 记笔记、改成公开，都要求当前能学习这一章。付费章节要有未退款、未过期的学习权益。试看章节不要求购买。
- 作者一直可以看、改、删自己的笔记。没有权益时不能再把笔记改成公开。
- 其他人只能看公开笔记。未购、已退款或权益到期时，付费章节的公开笔记不返回标题、正文、时间点和评论。
- 试看章节的公开笔记，没有购买权益的学员仍可阅读。
- 笔记里不保存资料地址。时间点只在播放器已经拿到本章视频时才能跳转。
- 删除或改回私有后，其他人再查正文和评论会得到「笔记不存在」或空内容。

## 互动和积分

- 同一人对同一篇笔记只能点赞一次。取消后再赞，赞数可以回来，积分不会再发。
- 给别人的公开笔记点赞，作者得 1 分，每天最多 5 分。自己给自己点赞不加分。
- 别人发表评论，作者得 1 分，每天最多 3 分。事件号分别是 `NOTE_LIKE:{笔记}:{点赞人}` 和 `NOTE_COMMENT:{评论}`。
- 管理员删除或转为私有必须填写原因，并写入操作审计。

正文用现有 Markdown 渲染，不解析原始 HTML。

## 验证

`NoteFlowTest` 在 `jdbc:h2:mem:learning_notes` 通过。覆盖越权修改、私有正文、公开后无权益不返回正文、改回私有、试看章节、并发点赞只记一次、重复点赞不再发分、恶意搜索词、非法章节和时间点、删除后不能再读。没有在 MySQL 上复测并发点赞。
