### 本轮修复（5 项）

| 编号 | 问题 | 影响 | 修复 |
|---|---|---|---|
| F-1 | 付费课程资料可被未购学员直接下载 | 严重：付费内容泄露 | 新增 `EntitlementProvider`；课程服务经 Feign 调交易服务判定已支付；无权益 403，交易服务不可用按未购处理 |

## 三、订单服务与 OpenFeign 调用关系

```
浏览器 ──▶ Gateway(18080, JWT + Token 版本校验)
              │  /orders/**                │ /courses/**, /teacher/**, /files/**
              ▼                            ▼
        kzai-trade(18084) ──Feign(内部签名)──▶ kzai-course(18083)
              ▲                                   │
              │ Feign(内部签名)                    │ Feign(内部签名)
              │                                   ▼
           kzai-user(18082)  ─────────────▶  kzai-trade
```

- `kzai-trade → kzai-course`：`GET /internal/courses/batch?ids=` 取实时课程快照（状态/分类/价格/有效期/可购买性）。
- `kzai-course → kzai-trade`：`GET /internal/trade/entitlements`、`/paid-courses` 判定学习权益。
- `kzai-user → kzai-trade`：`GET /internal/trade/orders/count-by-user/{userId}` 删除前关联校验。
- 所有内部调用携带 `X-Internal-Sign`（HMAC-SHA256）；网关拒绝外部访问 `/internal/**`。

## 十、尚未解决的问题与 M5 建议

1. **支付未接入**：`pay_order_no`/`pay_time`/`pay_channel` 保持为空；接入真实支付时需新增支付回调接口、幂等与对账，且不得复用本阶段接口直接改状态。
2. **幂等记录无过期清理**：`order_request_idempotent` 会随下单量增长，建议按月归档/清理历史记录（保留期与业务确认）。
3. **待审核列表全表扫描**：当前按审计表全量取最新记录，量级大时应落"课程最新审核状态"冗余列或缓存。
4. **超时未支付订单无自动关闭**：需求未包含定时任务，建议 M5 或后续以定时任务关闭超时待支付订单（并在关闭时保持明细一致）。
5. **文件存储仍为本地目录**：多实例部署需改为共享存储/对象存储，并补充视频流式播放（Range 请求）。
6. **M5 学习管理建议**：以 `order_detail`（`status∈{2,4,5}`）作为学习权益唯一来源，构建 `learning_lesson` 与进度上报接口；章节视频播放需校验权益（复用 `EntitlementProvider`）；学习有效期取订单快照 `valid_duration` + 支付时间计算，避免实时改价影响已购用户。
