## 9. 重建、删除与失败补偿

- **版本化重建**：新索引 bulk（`refresh=wait_for`）→ 数量核验（written==chunks，不等则删新版本并失败）→ `_aliases` 原子 remove+add → 核验成功前别名/旧索引不动（ES IT `aliasSwap_oldIndexKeptUntilVerified` 实证「切换前别名不变」）
- **失败**：bulk 失败/数量不一致/别名失败 → 删除新版本索引 → 任务失败落库（attempt≤5 重试补偿）；绝不虚报成功
- **删除**：逻辑删除立即生效（检索 MySQL 复核不可通过）→ DELETE 任务 `delete_by_query` 清理向量（e2e 实证 count=0）
- **重启补偿**：ApplicationReady 将「执行中」重置「待处理」（代码 + 状态机设计）
- **修复记录**：`_aliases` 单动作条目禁止多操作（remove/add 需两条）——实测 400 后修正

- 流程实测：`退款规则…` → RouteAgent=KNOWLEDGE → searchKnowledge → ES TopK → 授权过滤 → 回答引用「根据知识库「文档名」：…」→ **1003 RAG_SOURCE**（docId/chunkId/docTitle/score/snippet）→ 1002（agent=KNOWLEDGE）
