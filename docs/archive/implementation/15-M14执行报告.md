## 7. STT 后端实现要点

JWT（网关）→ UserContext 可信身份 → 空文件/大小/魔数/伪造扩展名校验 → **并发信号量** → Provider（MOCK：字节哈希从固定短语集确定性选文，**不识别内容**）→ 返回 `{text, provider, modelCode, mock, requestId}`。失败受控（EMPTY_FILE/FILE_TOO_LARGE/UNSUPPORTED_AUDIO/FORGED_EXTENSION/STT_PROVIDER_ERROR）。

## 8. TTS 音频流实现要点

`POST /audio/tts-stream`（form text）：空/超长校验 → 并发护栏 → MOCK 生成合法 WAV（16kHz/16bit PCM，可被浏览器 `<audio>` 真实播放）→ **chunked 写出** + `Content-Type: audio/wav` + `X-Tts-*` 头（Provider/Model/**Mock:true**/**Streaming:false 非流式如实标注**）。失败以 JSON R 结构返回（前端按 Content-Type 区分）。

## 9. Gateway 路由与身份权限

`/audio/**` 独立路由（置于通配之前，与 /chat、/session、/admin 兼容）；未登录 401；身份仅取网关注入头；学员可用语音；无密钥下发前端；上传大小/并发/文本长度三重限制；日志不含音频字节与识别正文。
