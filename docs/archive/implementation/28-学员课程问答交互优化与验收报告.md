## 1. 发现的原始问题（开发前检查）

| # | 问题 | 严重度 |

## 4. 课程选择与搜索实现

- el-select filterable remote：初始加载前 50 门上架课程（本地过滤）；输入关键词远程搜索；加载中/空状态/失败重试按钮齐全
- 选项显示：课程名 +（免费/¥价格）；同名课程显示 ID 尾号 6 位辅助区分（duplicateNames 集合检测）
- 选中 value = 真实 courseId 字符串；提交 JSON "courseId":"2112..."（后端 Long 字段字符串安全反序列化）

## 5. 权限与课程状态检查

- 前端：下拉选项过滤 status===2（仅上架）；路由预选校验课程存在+上架（不通过提示重新选择，不自动选中）
- 后端（未改动，原有规则）：validateAndAuthorize → learnOutline 校验课程存在/章节归属；章节关联提问复用学习权益（fail-closed）；未发明新限制（课程级提问不要求购买——与原始需求一致）
- 披露：learnOutline 不校验下架状态（下架课 API 直提 code=200）——前端已保证正常用户不可达；后端最小修复建议见 §13

## 6. 雪花 ID 精度验证

- 后端课程列表 JSON："id":"2112593414044803073"（Long→字符串序列化，既有配置）
- 前端全链路字符串：下拉 value/表单/提交体均字符串；已删除 Number(courseId)
- 实测提交：courseId="1001"（老数据小 ID）与 19 位雪花 ID 均正确反序列化写入 interaction_question.course_id（DB BIGINT 精度无损）
