## 1. course_content 关联字段核查（DOCX 原文定论）

《数据库设计说明书》3.3.4 原文：

| 字段 | 说明（原文） |
|---|---|
| id | BIGINT 否 - **课程内容ID，与 course.id 一致** |
| course_introduce | TEXT 课程介绍 |
| use_people | VARCHAR(255) 适用人群 |
| course_detail | LONGTEXT 课程详情 |
| dep_id | BIGINT 是 NULL **部门ID** |

- 正确关联键：**course_content.id = course.id（1:1 共键设计）**；代码实证：CourseService.buildDetail 使用 `contentMapper.selectById(course.getId())`
- dep_id = 部门ID（允许 NULL，当前业务未启用）——289 行全 NULL 是正常状态，不是孤儿数据

## 2. 上一报告统计矛盾的解释（31 号更正）
