# 46-管理端菜单点击失效与退出登录修复报告（M15.14-R10）

> 执行依据：用户《（P0）修复管理端保留菜单中点击无跳转的页面》指令。
> **结果：agent-browser 实测当前版本 8 菜单+个人中心全部跳转成功、退出登录链路（confirm→清除→跳登录）完整验证通过；同时完成 4 项防御性加固覆盖用户环境失败链路。控制台警告 0 新增。完成后暂停等待验收。**

## 1. 复现结果与根因分析

当前版本 agent-browser（Chromium）实测不可复现「点击无响应」：8 个保留菜单逐点全部跳转成功（用户管理→/admin/users、分类管理、课程审核、Prompt、知识库、AI 评测→/admin/ai/evaluations、操作日志→/admin/operation-logs、系统参数、个人中心）；退出登录 confirm→清除→跳登录页完整。

用户环境失败链路定位（3 条，均已完成防御性加固）：

| # | 失败链路 | 根因 | 修复 |
|---|---|---|---|
| 1 | 菜单点击停留当前页 + Unhandled error | 守卫内动态 import('./menuConfig') 失败（dev server 重建后旧 chunk 404 / Safari 慢网）→ beforeEach 抛异常 → vue-router 导航中止 → el-menu 不 catch → 停留当前页 | 改静态 import（roleAllowed/ROLE_HOME 顶层引入）+ 守卫全量 try/catch 兜底（任何异常 console.error + 跳 /login，绝不产生 Unhandled） |
| 2 | 退出登录两次点击无响应 | store.logout() 中 authApi.logout() 401（token 已过期）reject 未捕获 → Unhandled rejection → router.push('/login') 不执行 → 停留原页（但 token 实际已清——刷新才见登录页，表现=无响应） | onLogout try/catch + finally 强制跳登录（接口失败也清场登出，console.warn 留痕） |
| 3 | Safari 长会话 | 动态 import 缓存/网络 | 同 1（静态化后消除） |
