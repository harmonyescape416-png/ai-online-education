# 49-学习页权限误杀修复报告（M15.15）

> 执行依据：用户《修复「我的学习-课程」返回「您没有访问该页面的权限」》指令。
> **根因：M15.14-R8 菜单裁剪守卫误杀学员章节学习深链。已修复并 E2E 实测：/learn 直链放行、卡片点击链路恢复、管理端裁剪拦截行为不变。完成后暂停等待验收。**

## 1. 根因

M15.14-R8 守卫 roleAllowed('/learn/:courseId', roles)——MENU_CONFIG 无 /learn 前缀（章节学习页不在菜单显示）→ 返回 false → 重定向 /courses + 提示「您没有访问该页面的权限，已返回首页」。学员核心流程被裁剪守卫误杀（复现实测：/learn/1001 → 重定向 /courses，blocked=true）。

## 2. 权限规则梳理（明确）

| 路径 | 所需角色 | 真实权限校验 |
|---|---|---|
| /learn/:courseId | STUDENT（学员）——teacher/admin 前端放行由后端权益裁决 | 后端 EntitlementService.resolve 权威校验（学习页加载/章节播放/进度均走权益 fail-closed） |
| /learning（我的学习列表） | STUDENT/ADMIN（路由 meta） | 后端 lesson 数据按 userId 隔离 |
| /notifications | 全角色（铃铛入口） | 后端按 recipient_id 隔离 |

## 3. 修复

menuConfig.js 新增菜单外功能页豁免清单：

export const HIDDEN_ALLOWED = ['/learn', '/notifications']

roleAllowed 优先匹配豁免前缀（菜单不显示、路由可达）；后端 EntitlementService 权益校验不变（未授权课程的学习请求仍被后端拒绝——前端放行不等于越权）。

## 4. E2E 验证（agent-browser 实测）

| 场景 | 结果 |
|---|---|
| student 直链 /learn/1001 | 不再拦截（blocked=false），学习页渲染（课程标题+返回我的学习入口） |
| 我的学习 → 点击「开始学习」 | 跳转 /learn/2112593404091719681（真实课程 ID）blocked=false |
| admin 直连 /learn/1001 | 前端放行（后端权益权威裁决——符合分层） |
| 管理端裁剪页（dashboard/outbox） | 拦截行为不变（R8 设计保留） |

## 5. 回归

- build 3.06s；mvn clean install 308 tests 全绿（306 通过）
- 业务数据零变化；后端零改动

## 6. 文件

- 修改：router/menuConfig.js（HIDDEN_ALLOWED 豁免清单）
- 新增：docs/49-学习页权限误杀修复报告.md

## 7. 结论

守卫误杀修复：学员「我的学习 → 课程卡片 → 章节学习」全链路恢复；裁剪守卫对被裁剪管理页的拦截保持不变；权限分层清晰（前端菜单级+后端权威校验）。
