# 53-昵称头像刷新回读修复报告（M15.15 补充②）

> 执行依据：用户《刷新前端页面时保存的数据没有显示出来》排查修复指令。
> **根因：ProfileView onMounted 只回填了手机号，昵称/头像回读未挂载——刷新后 store.profile 有数据但表单空白。一行修复+实测通过。完成后暂停等待验收。**

## 1. 根因（数据流断点定位）

| 环节 | 状态 |
|---|---|
| 保存持久化 | 正常（PUT /users/me → user_profile_ext 持久化——52 号已修） |
| 刷新后接口返回 | 正常（路由守卫预载 store.profile——GET /users/me 含 nickname/avatarUrl） |
| **页面回填** | **onMounted 只回填 cellPhone**——nickname/头像回填缺失（fillExt 未在挂载时调用） |

数据流断点：store.profile（含数据）→ **表单**——刷新进入 /profile 时 onMounted 未执行 fillExt，导致输入框空白、观感=「保存的数据没显示」。头像因直接绑定 store.profile?.avatarUrl（响应式）实际能显示，但输入框昵称确实不回显。

## 2. 修复（一行级）

onMounted 补 fillExt()（统一回填昵称；头像绑定 store 响应式自动显示；cellPhone 保持原回填）。

## 3. 实测（刷新 /profile，agent-browser）

| 项 | 结果 |
|---|---|
| 昵称输入框回读 | 「hjhjh」（用户实际保存的值——非测试数据） |
| 头像显示 | src=/users/me/avatar/file/…（avatarShown=true） |
| 手机号回填 | 13800138000 |
