## 2. 数据更新触发与生效范围

| 触发 | 数据流 | 生效范围 |
|---|---|---|
| 保存昵称（ProfileView 保存资料） | PUT /users/me → fetchProfile → store.profile 更新（Pinia）→ MainLayout computed 即时响应 | 顶栏昵称 + 个人中心表单 |
| 上传头像（POST /users/me/avatar） | 上传 → avatarUrl 带版本参数（?v=ts）→ fetchProfile → store 更新 → 顶栏 img src 更新 | 顶栏头像 + 个人中心预览 |
| 刷新页面 | 守卫预载 profile（含扩展资料）→ 顶栏/表单一致 | 全站 |

一致性保证：顶栏与个人中心共用同一数据源（store.profile）——单点更新全站同步；avatarUrl 带版本参数破除覆盖式同 URL 的浏览器缓存。

## 4. 失败处理与状态回退

| 场景 | 行为 |
|---|---|
| 头像上传失败 | 清除本地预览（回退旧头像显示）+ ElMessage.error + store 不变更（顶栏保持旧头像） |
| 昵称保存失败 | ElMessage.error + 输入框保留用户输入 + store 不变更（顶栏保持旧昵称） |
| 退出登录 | store 清空 → 顶栏回到登录前状态 |
