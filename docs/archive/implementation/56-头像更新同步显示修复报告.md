# 56-头像更新同步显示修复报告（M15.15 补充④）

> 执行依据：用户《修复头像显示区域与页面顶部不同步更新》指令。
> **根因：头像更新依赖 fetchProfile 异步回填（时序竞争），个人中心用本地预览即时显示而顶栏等待 store 更新——出现部分区域更新部分未更新。修复：上传/保存响应直更 store（单点数据源即时生效），实测顶栏与预览同时更新。完成后暂停等待验收。**

## 1. 根因

| 区域 | 更新机制（修复前） | 差异 |
|---|---|---|
| 个人中心头像 | avatarPreview（本地 blob）——change 事件立即设置 | 即时显示 |
| 顶栏头像 | computed 依赖 store.profile.avatarUrl——等待 fetchProfile() 异步回填 | 时序竞争：fetchProfile 慢/失败时顶栏停留旧头像 |

结果：预览已新、顶栏未变——与用户反馈完全吻合。

## 2. 修复（ProfileView.vue）

1. **上传响应直更 store**：const resp = await profileApi.uploadAvatar(fd) → store.profile.avatarUrl = resp.avatarUrl（响应带版本参数）+ store.profile.avatarVersion = Date.now()（响应式版本）——顶栏 computed 即时重算，不等 fetchProfile
2. **昵称同步直更**：store.profile.nickname = profileForm.nickname（保存后顶栏即时）
3. **fetchProfile 保留为兜底一致性**（直更后仍跑，服务端状态收敛）
4. **失败回退**（R6 既有）：上传失败清除 avatarPreview + store 不变更（顶栏保持旧头像）
