## 2. 头像刷新不显示——根因与修复

排查链（后端 jpg 链路完全正常）：上传 jpg → 200 落盘 3.jpg（209 字节）→ 网关访问 HTTP 200 image/jpeg。

**真正根因（浏览器实测定位）**：avatarUrl 存储为**服务端相对路径** /users/me/avatar/file/3.jpg——前端 img 直接使用 → dev 环境请求发到 **5173 vite dev server**（/users/** 不在 /api 代理列表）→ **vite SPA fallback 返回 index.html（200 text/html）** → **破图**。实测对照：img fetch 返回 200 text/html（修复前）。

**修复**：新增 **withApiBase()**（utils/format.js）——服务端相对路径统一加 **/api 前缀**（dev 走 vite 代理→网关；prod 同源 /api）——**ProfileView + MainLayout 顶栏两处 img src 接入**。

实测（刷新后）：顶栏与个人中心 img fetch 均 **200 image/jpeg**；截图（07-avatar-fixed.png）顶栏+个人中心头像**同图显示**、昵称 111、无横向溢出。
