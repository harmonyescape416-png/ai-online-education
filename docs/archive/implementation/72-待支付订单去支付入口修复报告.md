| 修复 | 内容 |
|---|---|
| **焦点轮廓品牌化统一**（main.css 全局） | `*:focus-visible { outline: 2px solid #4F46E5 }` + `*:focus:not(:focus-visible) { outline: none }`——鼠标点击无轮廓/键盘导航品牌色（跨浏览器/移动端一致） |
