# 75-个人中心头像撑破首屏修复报告

> 执行依据：用户指令（avatar-img 无尺寸样式——student01 原图 899×1259 撑破首屏；只改 ProfileView.vue）。**完成后暂停等待验收。**

## 一、根因

**ProfileView.vue 从未包含 `<style>` 块**——`.avatar-img`（img 标签）零尺寸约束 → 浏览器按原图 899×1259 渲染 → 昵称/换手机号/保存资料被推出视口（实测保存按钮 y=1913）。

## 二、修复内容（追加 `<style scoped>`）

```css
.avatar-row { display: flex; align-items: center; gap: 14px; min-width: 0; overflow: hidden; }
.avatar-img { width: 96px; height: 96px; object-fit: cover; border-radius: 50%; flex-shrink: 0; display: block; }
.avatar-placeholder { /* 占位首字母同尺寸圆形 */ display: flex; align-items: center; justify-content: center; background: #eef2ff; color: #4F46E5; font-size: 32px; font-weight: 600; }
@media (max-width: 768px) { .avatar-row { flex-wrap: wrap; } }
```

- 适用于 **img.avatar-img 与占位首字母**（统一类）
- **顶栏 30px 圆形头像不受影响**（独立样式，实测 30x30）

## 三、验收（双宽度实测）

| 宽度 | 头像 | object-fit | 圆角 | 保存资料同屏 | 横向滚动 |
|---|---|---|---|---|---|
| **1440** | **96×96**（原 899×1259） | cover | 50% | **true**（y=706<880）✅ | — |
| **390** | **96×96** | — | — | — | **无** ✅ |

- **换大图上传后预览仍 96×96**（object-fit: cover 保证裁切不变形）
- 首屏同时可见：头像 + 昵称 + 保存资料 ✅
