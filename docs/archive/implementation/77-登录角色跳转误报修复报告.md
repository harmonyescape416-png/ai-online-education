# 77-登录角色跳转误报修复报告

> 执行依据：用户指令（登录固定跳 /courses 致教师/管理员守卫误报「无权限」；只改 LoginView.vue；不改 roleAllowed）。**完成后暂停等待验收。**

## 一、根因

LoginView 登录成功固定 `router.push(route.query.redirect || '/courses')`——教师/管理员菜单不含 /courses → 路由守卫弹出「您没有访问该页面的权限，已返回首页」→ 再跳角色首页（最终落点正确但误报）。

## 二、修复（只改 LoginView.vue——不改 roleAllowed 权限规则）

```js
const redirect = route.query.redirect
const roles = data.roles || store.roles
if (redirect && typeof redirect === 'string' && roleAllowed(redirect, roles)) {
  router.push(redirect)          // 有 redirect 且该角色允许
} else {
  router.push(ROLE_HOME[roles?.[0]] || '/courses')  // 无 redirect → 角色首页
}
```
