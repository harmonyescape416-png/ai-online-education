## 一、全局问题（4 条）

### 提示词 G1：统一时间格式化
```
全局排查所有页面和组件中的时间显示：凡是直接渲染后端返回的 ISO 字符串（如 "2026-10-19T09:53:27"）的地方，
统一封装一个 formatDateTime 工具函数（dayjs 或原生实现均可），输出 "YYYY-MM-DD HH:mm:ss"。
已知问题点：个人中心「注册时间」显示为 2026-10-19T09:53:27；我的订单表格「下单时间」列被列宽截断。
验收标准：全项目搜索不再有直接渲染原始 ISO 串的位置；订单时间列完整显示年月日时分秒。
```

### 提示词 G2：补齐列表页分页与导出
```
需求 3.1.1 要求"列表页统一提供查询、重置、分页与导出"。检查课程浏览、我的订单、课程问答等列表页，
补齐 Element Plus 的 el-pagination（页码 + 每页条数选择，默认 10 条），并接通后端分页参数；
为管理端列表补"导出"按钮（前端导出 CSV 即可）。学员端不强制导出。
验收标准：三个列表页均有分页器且翻页请求正确；导出文件内容与当前筛选结果一致。
```

### 提示词 G3：通知铃铛面板
```
顶部导航的通知铃铛目前只有红点数字，点击无响应。实现一个通知下拉面板：
展示最近 20 条站内通知（标题、时间、已读状态），支持"全部已读"和点击跳转对应页面；
接口不存在的先 mock 数据结构并留 TODO 注释。通知列表为空时显示空状态插画+文案。
验收标准：点击铃铛展开面板、再次点击或点外部关闭；红点在全部已读后消失。
```

### 提示词 G4：统一空状态与加载骨架屏
```
统一全站空状态与加载态：封装 EmptyState 组件（图标 + 主文案 + 可选引导按钮），
课程问答"暂无问答记录"等纯文字空态全部替换；列表/卡片页在请求期间使用 el-skeleton 骨架屏。
验收标准：无数据页面不再是裸文字；异步请求期间有骨架屏且不出现布局跳动。
```

## 二、AI 工作台（3 条）

### 提示词 A1：会话自动命名
```
AI 工作台左侧会话列表当前全是"新的对话/你好"等无意义标题。修改逻辑：
用户发送第一句提问后，取问题前 15 个字符（去掉换行与多余空格）作为会话标题并更新列表；
标题为空时回退"新的对话"。保留现有的手动重命名功能。
验收标准：新会话首问后标题立即变化；刷新页面后标题持久化。
```

### 提示词 A2：隐藏技术细节（P0）
```
AI 工作台右栏「模型状态」卡片直接暴露 DASHSCOPE、会话 ID、Redis TTL 等内部信息，输入区下方
出现"流中断 11s/60s"技术提示。修改：
1. 右栏改为学员友好文案（如"AI 助手在线 · 模型：通义千问"），技术信息折叠进一个默认收起的
   「调试信息」el-collapse，或开发环境才显示；
2. "流中断 xx s/60s"改为用户可读提示"网络波动，正在恢复…"，秒数计数仅开发环境输出到 console；
3. 流式生成进行中才显示"停止"按钮，样式与主题一致，生成结束自动隐藏。
验收标准：普通学员界面看不到任何 Redis/DASHSCOPE/流中断字样。
```

### 提示词 A3：三栏布局优化
```
AI 工作台三栏在中间消息区空间不足。修改：
1. 右栏（模型状态/欢迎语/热门问题/功能提示）改为可收起的侧抽屉，默认在有消息时自动收起；
2. 会话列表项的编辑/删除图标热区放大到至少 32×32px，hover 时才显示，减少视觉噪音；
3. 空会话时把欢迎语+推荐问题渲染到消息区中央作为引导气泡，点击推荐问题直接填入输入框。
验收标准：消息区最小宽度有保障；收起右栏后刷新页面记住状态。
```

## 四、我的学习（2 条）

### 提示词 L1：进度状态语义（P0·已修订）
```
我的学习卡片状态语义：状态判定依据「是否存在学习记录」，不能只看进度百分比。
（背景：学习记录证明有学员虽 0% 但确有学习行为，仅凭 0% 判"未开始"会错误降级真实状态）
修改状态规则：
无学习记录（上次学习时间为空且累计时长为 0 秒）→ "未开始"，按钮"开始学习"；
有学习记录但进度 0%（已开始、尚未完成章节）→ 保留"学习中"，补充副文案"已开始 · 0/3 章"
消除观感矛盾；100% → "已完成"。标签颜色随状态区分。
验收标准：无学习记录的 0% 卡片显示"未开始"；有学习记录的 0% 卡片保留"学习中"且副文案可见。
```

### 提示词 L2：续学提示与信息层级
```
我的学习卡片信息 5 行小字平铺，无层级。修改：
1. "继续学习"按钮下方或按钮文案中体现断点："继续：第 N 章"；
2. 卡片保留：进度条、已完成 x/y 章、最近学习章节三行；"上次学习时间/累计时长"收进 hover
   提示或次级文本；时长统一格式"x 分 x 秒"。
验收标准：卡片主信息一眼可读；断点章节在按钮区可见。
```
