## 一、按严重程度排序的问题清单

### 🔴 P0（2 项，阻断级）

**P0-1：全站菜单点击失效（学员端 6/6）**
- 现象：登录后点击「我的学习/我的订单/个人中心/AI 工作台/课程问答/通知中心」全部停留在课程浏览页
- 但直链访问（`#/learning`、`#/orders`、`#/profile`、`#/ai`、`#/notifications`）全部正常渲染
- 定位：路由与页面本身完好，是**菜单组件的点击事件处理器失效**——与昨日 admin 端 6 个菜单失效同源，今日已扩散到学员端，怀疑昨日菜单裁剪（menuConfig.js 重构）或视觉升级改动引入全局回归
- 影响：用户只能靠直链/刷新使用系统，主导航瘫痪

**P0-2：admin 登录返回 200 但不跳转**
- 现象：`POST /api/auth/login` 返回 200（接口成功），页面仍停留在登录页，无任何错误提示
- 影响：管理员完全无法进入系统（叠加 P0-1，管理端当前实质不可用）
- 排查方向：登录成功后的 token 存储→角色判断→跳转链路；注意排除 HMR 干扰后人工复核
