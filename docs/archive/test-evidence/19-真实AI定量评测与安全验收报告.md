## 8-10. 指标计算方法（评测执行后将按此口径出具）

- **意图准确率** = 路由命中数 / 有 expected_intent 的已尝试样本数（按 category 分组给出样本数与准确率 + 错误分类明细混淆矩阵，`EvalMetricsService` byIntent/byCategory）；Prompt 版本取批次 `prompt_snapshot`。
- **RAG Hit@6** = 期望黄金文档出现在 Top6 有效召回（真实 v4 embedding + REAL 索引）的用例数 / **有 expected_doc_id 的用例数（有效分母 = 8）**；expected_doc_id=NULL 用例不进分母（语料缺失≠检索失败）；每条记录实际 Top6 docId/chunkId。
- **拒答 P/R**（正类=应拒答，should_refuse=1 共 5 条）：TP=应拒答且 refusal；FP=不应拒答却 refusal（falseRefusalCount）；FN=应拒答未拒答；TN=不应拒答且作答。Precision=TP/(TP+FP)，Recall=TP/(TP+FN)=summary.correctRefusalRate；leak_suspected 单列。
- **延迟/token**：P50/P95/平均分别按 route/rag/answer/端到端四列与 prompt/completion/total tokens 统计（真实 provider usage；NULL=unavailable 如实标注）；**首字延迟以真实会话链路 ai_model_call_log 的历史统计补充说明（评测态非流式不产出）**；失败请求数与实际 API 调用次数按 ai_model_call_log + TOOL_AUDIT 对账。
