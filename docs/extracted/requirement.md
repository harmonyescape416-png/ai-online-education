1. 引言
1.1 编写目的
本文档是对课栈智伴——AI 智能在线教育平台进行需求分析的结果，说明了平台的角色、功能需求、对外接口与约束。这些规格是系统设计、数据库设计、接口开发和测试用例编写的共同依据。
本文档的编写目的是明确平台边界与功能范围，为项目计划、系统设计、开发实现和验收测试提供统一口径。后续的《系统设计说明书》《数据库设计说明书》《软件测试报告》均以本文档为基础编写。
本文档的预期读者为项目负责人、系统设计人员、开发人员、测试人员、企业导师与验收人员。
本文档由本人在企业导师付红星指导下整理。需求覆盖本人参与开发的课程查询、会话接口、OpenFeign 调用与 AI 功能联调部分；平台级功能与公共模块的需求用于说明系统整体上下文，个人参与边界见《系统设计说明书》第 10 章。
1.2 项目背景
开发项目名称：课栈智伴——AI 智能在线教育平台
项目任务提出者：沧州云智大数据产业园有限公司
项目开发者：实习学生（参与需求整理、接口开发与 AI 功能联调）
用户：学员、教师/运营、管理员
实现该软件的计算机网络：局域网 / 广域网（基于 B/S 架构的 Web 应用）
项目以职业教育课程业务为背景，在课程、交易、学习等基础服务之上新增 aigc 服务，将大模型对话、课程推荐、课程查询、预下单、知识库问答与语音交互接入现有业务，形成「咨询—推荐—决策—学习」的完整链路。
2. 总体描述
2.1 产品前景
职业教育线上化程度不断提高，学员在选择课程时面临课程信息分散、课程与岗位需求匹配困难、咨询响应慢等问题；教师在课程答疑上重复投入，运营人员也缺少统一的问答与效果数据。传统课程页面只能提供静态介绍，无法根据学员基础与目标给出解释和推荐。
课栈智伴在现有课程、交易、学习服务之上增加 AI 能力：学员可以用自然语言咨询课程、获取推荐、查询价格与章节、完成预下单；教师可以维护课程与问答，查看学情；管理员可以维护知识库、提示词与评测用例，观察模型效果。平台将大模型能力限制在可追溯的工具调用与知识库检索范围内，避免编造课程信息，并为后续扩展更多智能体保留接口。

2.4 假设和依赖
AS1：系统运行于 JDK 17 环境，后端服务本地或容器化启动，依赖 MySQL 8、Redis 7、Elasticsearch 8 与 Nacos 2.3 四个中间件。
AS2：大模型通过 DashScope 的 OpenAI 兼容接口调用 qwen-plus，服务端可访问公网；模型超时按 60 秒配置，限流时返回 429 并提示重试。
AS3：用户通过 Chrome 126 或 Edge 126 及以上版本访问；语音功能需要麦克风权限，且页面运行在 HTTPS 或 localhost 下。
AS4：账号由管理员统一创建，学员暂不开放自助注册；教师账号与课程归属绑定，AI 系统账号仅用于自动回复落库。
AS5：课程资料、FAQ 与购买规则由教师/运营提供，经管理员审核后入库；知识库更新为异步任务，入库完成前检索结果可能滞后。
3. 详细需求描述
3.1 对外接口需求
3.1.1 用户界面
系统为 B/S 架构的 Web 应用，前端采用 Vue 3、Vite 与 Element Plus。页面统一采用顶部信息栏、左侧导航与右侧内容区的布局，不同角色登录后仅展示其权限范围内的菜单。AI 工作台采用「会话列表—消息区—输入区」三栏结构，消息区支持 Markdown、代码块、课程卡片与订单卡片渲染，生成过程中展示停止按钮与打字光标。
学员端以课程与 AI 对话为主，教师端以课程、资料与问答为主，管理端以表格、表单与统计卡片为主。列表页统一提供查询、重置、分页与导出；表单页统一提供必填校验、提交确认与结果提示。
3.1.2 硬件接口
系统为纯软件系统，运行于通用服务器与普通 PC，不依赖专用硬件。语音功能使用客户端麦克风与扬声器：录音通过浏览器 MediaRecorder 采集，播报通过音频元素播放；无麦克风或权限被拒时回退为文字输入。
3.1.3 软件接口
（1）数据库接口：通过 JDBC 连接 MySQL 8，使用 MyBatis-Plus 完成对象与关系映射，连接池管理连接资源。
（2）缓存接口：通过 Spring Data Redis 连接 Redis 7，保存会话记忆、生成状态、停止标识与热点数据；Redis 不可用时降级为数据库访问。
（3）向量库接口：通过 Spring Data Elasticsearch 连接 Elasticsearch 8，写入文档切片向量并执行相似度检索。
（4）注册与配置接口：服务启动时向 Nacos 2.3 注册实例，并从 Nacos 读取共享配置、模型参数与 Prompt 模板。
（5）服务调用接口：aigc 通过 OpenFeign 调用课程、交易、学习与用户服务，携带 userId 与 requestId，统一超时与异常处理。
（6）大模型接口：通过 OpenAI 兼容的 Chat Completions 接口调用 qwen-plus，支持流式与非流式两种模式。
（7）语音接口：调用语音转文字与文字转语音服务，音频以流或文件方式传输，不落业务库。
（8）文件接口：课程封面、视频与附件通过文件服务上传与访问，数据库仅保存文件地址与元数据。
3.1.4 通信接口
客户端与服务器之间采用 HTTPS + JSON 的 REST 接口；AI 对话使用 SSE（text/event-stream）长连接，服务端按事件逐条推送，事件负载为 JSON。语音上传使用 multipart/form-data，服务间调用使用 HTTP/JSON。
SSE 事件约定：1001 为文本增量，data 中携带 content；1003 为参数事件，携带课程卡片或订单卡片参数；1002 为结束事件。客户端收到 1002 后关闭连接，异常断开时保留已生成内容并提示重试。
3.2 功能需求
系统功能按角色与功能域划分为管理员、教师/运营、学员、AI 智能体与公共功能五部分，共 30 项。每项按需求名称、简要描述、主要参与者与步骤描述说明。
3.2.1 管理员功能需求
3.2.1.1 用户管理
需求名称：用户管理
简要描述：管理员维护平台账号与角色。支持按登录账号、姓名、角色与状态组合查询；可新增账号、修改资料与角色、重置密码、启用/禁用与删除。账号与业务数据关联，删除前须先处理其课程、订单或会话。
主要参与者：管理员
步骤描述：
1、进入「用户管理」页面，输入关键字并选择角色、状态，点击「查询」；
2、点击「新增用户」，填写登录账号、姓名、角色、手机号与初始密码后提交；
3、对已有账号点击「编辑」修改资料或调整角色，点击「重置密码」恢复为初始密码；
4、点击「启用/禁用」切换状态，禁用后该账号已签发的 token 立即失效；
5、点击「删除」时系统校验关联数据，存在课程、订单或会话时提示先处理。

3.2.1.2 课程分类管理
需求名称：课程分类管理
简要描述：管理员维护课程的一级、二级分类，支持树形展示、新增、重命名、排序、启用/禁用与删除。分类下存在课程时不允许删除；分类禁用后不再出现在学员端筛选与教师端选择项中。
主要参与者：管理员
步骤描述：
1、进入「分类管理」页面，查看一级分类与其下级分类的树形结构；
2、点击「新增分类」，填写名称、上级分类、排序号与状态后提交；
3、点击「编辑」修改名称或排序，拖拽调整同级分类顺序；
4、点击「启用/禁用」切换状态，禁用后该分类及下级分类不再对学员展示；
5、点击「删除」时系统校验分类下是否存在课程，存在时提示先迁移课程。

3.2.1.3 课程审核与上下架
需求名称：课程审核与上下架
简要描述：教师提交课程上架申请后，管理员审核课程标题、封面、分类、价格、简介与章节完整性。审核通过后课程上架；管理员也可对违规课程强制下架并填写原因。下架后学员端不可见，AI 课程查询工具不再返回该课程。
主要参与者：管理员
步骤描述：
1、进入「课程审核」页面，按状态筛选待审核课程；
2、点击课程查看基本信息、章节目录与内容预览；
3、点击「通过」完成上架，或点击「驳回」填写驳回原因并退回教师修改；
4、对已上架课程点击「强制下架」，填写下架原因，课程状态置为已下架；
5、审核与下架操作写入操作日志，并向课程负责人发送站内通知。

3.2.1.4 知识库管理
需求名称：知识库管理
简要描述：管理员维护 RAG 知识库文档，支持上传课程介绍、FAQ 与购买规则（PDF/Markdown），系统解析后按 500 字切片、50 字重叠向量化写入 Elasticsearch。支持重建索引、删除文档与检索测试，文档可关联到具体课程。
主要参与者：管理员
步骤描述：
1、进入「知识库管理」页面，选择关联课程并上传 PDF 或 Markdown 文档；
2、系统解析文档并展示切片数量、字符数与向量化状态；
3、对解析失败的文档点击「重新解析」，查看失败原因；
4、点击「重建索引」，系统按新文档重新生成向量并替换旧索引；
5、点击「检索测试」，输入问题查看 topK 片段、相似度与来源文档；
6、点击「删除」同时移除文档元数据与向量，检索不再召回该文档。

3.2.1.5 Prompt 模板管理
需求名称：Prompt 模板管理
简要描述：管理员按智能体维护 system prompt、欢迎语与推荐问题，包括路由、推荐、咨询、购买与知识讲解五类模板。模板保存为草稿后可发布到 Nacos，新会话立即生效，历史会话不受影响；支持查看版本与回滚。
主要参与者：管理员
步骤描述：
1、进入「Prompt 模板」页面，按智能体选择模板；
2、编辑 system prompt、欢迎语与推荐问题，保存为草稿；
3、点击「预览」查看渲染后的提示词与变量占位符；
4、点击「发布」将配置写入 Nacos，新会话使用新模板；
5、在版本列表中选择历史版本执行回滚，回滚操作记录日志。

3.2.1.6 评测用例与批量评测
需求名称：评测用例与批量评测
简要描述：管理员维护评测用例（问题、期望意图、期望课程或关键词），批量执行路由与回答，统计意图准确率、召回命中率与拒答率，查看失败用例详情并导出结果。
主要参与者：管理员
步骤描述：
1、进入「评测看板」，点击「导入用例」上传 CSV 或逐条新增；
2、选择全部或指定用例，点击「批量评测」；
3、系统逐条调用路由与回答，记录实际意图、命中课程与耗时；
4、查看总准确率、按意图准确率与失败用例列表；
5、点击「导出」下载评测结果，失败用例可一键转为回归用例。

3.2.1.7 会话与问答监管
需求名称：会话与问答监管
简要描述：管理员按用户、时间、意图与关键词查询会话、消息与工具调用记录，查看引用来源与耗时；可对违规问答执行隐藏，对异常会话标记复核。监管操作只读原始消息，不做修改，保证审计可追溯。
主要参与者：管理员
步骤描述：
1、进入「会话监管」页面，按用户、时间区间与意图筛选会话；
2、点击会话查看消息列表、工具调用参数与引用来源；
3、切换到「问答监管」，查看课程提问与 AI/教师回复；
4、对违规内容点击「隐藏」，填写原因，学员端不再展示；
5、对异常会话点击「标记复核」，记录处理人与处理结果。

3.2.1.8 数据概览
需求名称：数据概览
简要描述：管理端首页展示用户数、课程数、今日会话数、今日提问数、待处理问答数、模型调用成功率与平均首字时延，支持按今日、近 7 天、近 30 天切换。
主要参与者：管理员
步骤描述：
1、登录后进入管理端首页；
2、查看核心指标卡片与近 7 天趋势图；
3、切换「今日」「近 7 天」「近 30 天」查看不同区间数据；
4、点击指标卡片跳转到对应的用户、课程、会话或问答列表。

3.2.1.9 操作日志
需求名称：操作日志
简要描述：系统记录登录、用户与角色变更、课程审核、知识库与参数变更等关键操作，包含操作人、IP、请求方法、参数摘要、执行结果与耗时。管理员可按条件查询、查看详情并导出，日志保留 90 天。
主要参与者：管理员
步骤描述：
1、进入「操作日志」页面，按操作人、类型、结果与日期区间查询；
2、点击日志行查看请求参数、返回结果与异常信息；
3、点击「导出」下载当前查询结果为 CSV；
4、系统按保留策略自动清理 90 天前的日志，清理动作单独记录。

3.2.1.10 系统参数
需求名称：系统参数
简要描述：管理员维护检索相似度阈值、topK、会话历史上限、模型超时、单用户每日调用上限等参数。参数保存前做范围校验，发布后热更新到 aigc 服务，变更写入操作日志。
主要参与者：管理员
步骤描述：
1、进入「系统参数」页面，查看当前参数值与说明；
2、修改相似度阈值（0～1）、topK（1～20）、历史上限与模型超时；
3、点击「保存」，系统校验取值范围，非法值返回明确提示；
4、点击「发布」将参数推送到 Nacos，aigc 服务监听后热更新；
5、在变更记录中查看修改人、修改前后值与生效时间。

3.2.2 教师/运营功能需求

3.2.4 AI 智能体功能需求
3.2.4.1 AI 会话与流式对话
需求名称：AI 会话与流式对话
简要描述：学员在 AI 工作台新建会话并提问，服务端通过 SSE 逐字返回回答，事件类型为 1001 文本、1003 参数、1002 结束；回答支持 Markdown 渲染，首字时间目标小于 3 秒。
主要参与者：学员、AI 智能体（系统）
步骤描述：
1、学员进入 AI 工作台，点击「新建会话」，系统返回 sessionId；
2、输入问题并提交，前端建立 SSE 连接；
3、服务端加载提示词与会话记忆，调用大模型；
4、前端接收 1001 事件逐字渲染回答，必要时接收 1003 参数事件；
5、生成结束接收 1002 事件并关闭连接；
6、模型超时或限流时返回可读提示，不写入空回复。

3.2.4.2 停止生成与会话历史
需求名称：停止生成与会话历史
简要描述：生成过程中可点击停止，服务端在 1 秒内终止模型输出并保存已生成片段；历史会话按更新时间倒序展示，最多 30 条，支持重命名与删除，删除时同步清理数据库与 Redis。
主要参与者：学员、AI 智能体（系统）
步骤描述：
1、在回答生成过程中点击「停止」，前端调用停止接口；
2、服务端写入停止标识，流式循环检测后结束输出；
3、系统只保存已生成片段，按 messageId 去重；
4、进入「历史会话」查看最近 30 条会话，按更新时间倒序；
5、点击会话加载历史消息与卡片参数；
6、重命名或删除会话，删除时同步清理数据库与 Redis。

3.2.4.3 多智能体意图路由
需求名称：多智能体意图路由
简要描述：路由智能体先对问题做非流式意图判断，输出推荐、咨询、购买、知识讲解或无关五类结果，再分发给对应专业智能体；寒暄与无关问题直接回复，解析失败时兜底到咨询智能体，路由调用不写入会话记忆。
主要参与者：AI 智能体（系统）
步骤描述：
1、接收用户问题，路由智能体加载路由提示词；
2、非流式调用模型，输出意图枚举；
3、按枚举查找推荐、咨询、购买或知识讲解智能体；
4、目标智能体加载自身提示词、记忆与工具，执行流式回答；
5、枚举解析失败时转咨询智能体，寒暄与无关问题直接回复。

3.2.4.4 课程查询工具与卡片
需求名称：课程查询工具与卡片
简要描述：模型从问题中抽取课程名称或 ID，调用课程查询工具，通过 OpenFeign 读取课程服务；工具携带 userId 恢复用户上下文，结果暂存并在流结束时通过 1003 事件返回课程卡片。
主要参与者：AI 智能体（系统）
步骤描述：
1、模型识别课程查询意图，抽取课程名称或 ID；
2、调用课程查询工具，从 ToolContext 取得 userId；
3、工具通过 OpenFeign 调用课程服务，返回名称、价格、封面与简介；
4、结果写入 ToolResultHolder，流结束时组装 1003 参数事件；
5、课程不存在或服务超时时返回可读提示，不编造课程信息。

3.2.4.5 购买预下单工具与卡片
需求名称：购买预下单工具与卡片
简要描述：购买意图下，模型调用预下单工具创建订单与订单明细，返回订单号、课程清单与金额，前端渲染订单确认卡片；只预下单不发起支付，金额以服务端计算为准，单位分，重复请求按幂等处理。
主要参与者：学员、AI 智能体（系统）
步骤描述：
1、模型识别购买意图，向学员确认目标课程；
2、调用预下单工具，携带 userId、courseIds 与 requestId；
3、交易服务校验课程状态与价格，创建订单与明细，状态为待支付；
4、工具返回订单号、课程清单与应付金额，流结束时推送订单卡片；
5、重复请求按 userId + requestId 幂等处理，不生成第二笔订单。

3.2.4.6 RAG 知识库问答
需求名称：RAG 知识库问答
简要描述：课程资料与 FAQ 经切片、向量化写入 Elasticsearch；提问时先检索 topK 6、相似度阈值 0.6 的相关片段，拼入 Prompt 后生成回答，并附来源文档或课程名；无召回时礼貌说明未找到，不编造信息。
主要参与者：AI 智能体（系统）
步骤描述：
1、问题经 Embedding 模型转为向量；
2、在 Elasticsearch 中按 topK 6、阈值 0.6 检索相关片段；
3、将片段与问题拼入 Prompt，标注来源；
4、模型生成回答，前端展示来源文档或课程名；
5、召回为空或 ES 不可用时说明未找到或降级为纯模型回答。

3.2.4.7 语音输入与输出
需求名称：语音输入与输出
简要描述：学员可录音提问，服务端调用语音转文字接口将结果填入输入框；回答支持文字转语音播报，可流式播放。麦克风需在 HTTPS 或 localhost 下使用，失败时回退文字输入，音频不落库。
主要参与者：学员、AI 智能体（系统）
步骤描述：
1、点击麦克风按钮，浏览器申请录音权限；
2、录音结束后上传音频，服务端调用语音转文字接口；

4、点击回答旁的「播报」，服务端调用文字转语音接口流式返回音频；
5、权限被拒或接口失败时提示原因并回退文字输入，音频不保存。

3.3 约束
（1）权限约束：所有业务接口均要求登录；未登录返回 401，越权返回 403；AI 会话按 userId 隔离，不能通过 sessionId 读取他人会话；管理端、教师端与学员端菜单按角色展示。
（2）角色约束：系统设管理员、教师/运营、学员三类角色，另设 AI 系统账号用于自动回复落库；教师只能管理本人创建的课程与问答，不能管理用户与系统参数。
（3）会话约束：同一会话同时只允许一个生成任务；停止后只保存已生成片段，不写入完整回答；历史会话最多返回 30 条，标题取首条问题前 100 字。
（4）模型约束：模型调用超时为 60 秒，限流时提示稍后重试；回答不得编造课程价格、优惠与退款规则，涉及事实的信息必须来自课程服务或知识库，并尽可能附来源。
（5）工具约束：课程查询工具只读，不修改课程数据；预下单工具只创建订单与明细，不发起支付；工具必须携带 userId；金额单位为分，以服务端计算为准；重复请求按 userId + requestId 幂等。
（6）知识库约束：文档按 500 字切片、50 字重叠，检索 topK 为 6、相似度阈值为 0.6；向量维度必须一致；重建索引期间旧索引继续可用；召回为空时礼貌说明未找到。
（7）状态约束：课程状态为草稿、待审核、已上架、已下架；订单状态为待支付、已支付、已取消；问答状态为待回复、已回复；会话状态为生成中、已停止；状态流转必须由服务端校验。
（8）密码与登录约束：密码使用 BCrypt 存储，不保存明文；新密码长度 6～20 位；JWT 按配置过期，账号禁用后已签发 token 立即失效；登录失败提示不区分账号不存在与密码错误。
（9）数据完整性约束：订单与明细、问题与回复、课程与章节通过外键或业务校验保持关联；删除课程、用户、分类、文档前须检查关联数据，避免孤立记录；删除操作采用逻辑删除或先校验后物理删除。
（10）运行环境约束：客户端需使用支持 ES2020 与 SSE 的现代浏览器；语音功能需 HTTPS 或 localhost；服务端需可访问大模型与语音服务；生产环境应配置 HTTPS、访问日志与备份策略。
